# Chatterino7 – Twitch + Kick-fork

Dette er en personlig fork av Chatterino7 for å bruke Twitch- og Kick-chat i samme fane.

## Hovedfunksjon

Velg en chatfane, åpne kanalvelgeren og velg **Multi**. Legg deretter til én eller flere Twitch- og Kick-kanaler. Meldinger fra begge plattformer vises samlet med plattformmerke, og aktiv sendekanal velges fra skrivefeltet.

Se [FORK_SETUP_NO.md](FORK_SETUP_NO.md) for full veiledning, GitHub-oppsett og bygging på Windows 11.

## Opphav og lisens

Basert på [Chatterino7](https://github.com/SevenTV/chatterino7), som igjen er basert på Chatterino 2. Koden distribueres under prosjektets eksisterende MIT-lisens.
